Acá voy a documentar las relaciones entre tablas para que sea más fácil editar las tablas a futuro========================================
MALKU - RELACIONES BASE DE DATOS
========================================

==================================================
USUARIOS
==================================================

usuarios.id
    ├── pedidos.usuario_id
    ├── carrito.usuario_id
    ├── favoritos.usuario_id
    ├── direcciones.usuario_id
    ├── membresias.usuario_id
    └── stock_movimientos.usuario_admin_id

--------------------------------------------------

Relaciones:
- Un usuario puede tener MUCHOS pedidos
- Un usuario puede tener UN carrito activo
- Un usuario puede tener MUCHOS favoritos
- Un usuario puede tener MUCHAS direcciones
- Un usuario puede tener MUCHAS membresías
- Un admin puede generar MUCHOS movimientos de stock

==================================================
CATEGORIAS
==================================================

categorias.id
    └── productos.categoria_id

--------------------------------------------------

Relaciones:
- Una categoría puede tener MUCHOS productos

==================================================
PRODUCTOS
==================================================

productos.id
    ├── producto_imagenes.producto_id
    ├── carrito_detalle.producto_id
    ├── pedido_detalle.producto_id
    ├── favoritos.producto_id
    └── stock_movimientos.producto_id

--------------------------------------------------

Relaciones:
- Un producto puede tener MUCHAS imágenes
- Un producto puede estar en MUCHOS carritos
- Un producto puede estar en MUCHOS pedidos
- Un producto puede ser favorito de MUCHOS usuarios
- Un producto puede tener MUCHOS movimientos de stock
